Search needs a relay. The public arXiv API sends no CORS header, so no browser can call it straight from a page. Opening this file directly still works — the radar falls back to public read-only proxies and retries them — but those are rate-limited and go down without notice. For search that always works, run python3 serve.py in this folder and open http://localhost:8787/arxiv_semantic_research_radar.html; the page then relays through your own machine.
